Idea 1 · One Compare tab for the whole profile

  1. 1A Compare tab in the Profile group. It takes builds from any weapon of the profile: My builds, the ★ pick, builds of a last run.
  2. 2One column is the baseline (★). Every difference is measured against it. Click ☆ on another column to make that one the baseline (works in this mockup).
  3. 3All columns are scored on one basis: each build's own conditions, the baseline's conditions, or every condition on. That keeps weapon A vs weapon B fair.
  4. 4Damage of the scored attack leads, with per-minute damage and score under it. The best value in each row is green.
  5. 5What it takes: the pieces to swap or re-gem and the skills you gain or lose, spelled out, so you know what to craft.
  6. 6Damage per attack for every column, so a build that is only better on one move stands out.
  7. 7Skills and equipment as a grid. Cells that differ from the baseline are marked; skills that are the same everywhere are folded away.
  8. 8A stale run is rescored now and flagged, with its run score, so +1.4 from an old run is never mistaken for a real gain.
  9. 9The compare tray stays at the bottom on every tab: add builds from Results, My builds or the Inventory, then open them here.
