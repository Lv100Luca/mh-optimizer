Design notes

  1. 1One card, Allowed armor sets, replaces "Excluded armor sets" and the piece search of "Allowed armor". Every set at or above the minimum rarity is listed, allowed by default.
  2. 2Set checkbox: checked = every piece allowed, empty = set disallowed, dash (indeterminate) = some pieces disallowed. Clicking a dash allows the whole set.
  3. 3The piece button shows allowed/total and opens a popover (MudPopover, like the Picker) with one checkbox per piece. Sets with one piece have no button: the set checkbox is the piece.
  4. 4Mapping: a whole set off goes to exclude_sets (as today, old profiles keep working). Single pieces off go to a new exclude_armor list. When the last piece of a set is turned off it folds into exclude_sets.
  5. 5Locks stay include_armor, stored exactly like the Results lock button (the only allowed piece of its kind). The Locked armor card keeps the per-kind chips and "Use the armor of". Pieces shut out by a lock show dimmed with the lock named; their checkbox is unchanged.
  6. 6B adds the lock button to each popover row, so a piece can be locked from Options too. Locking a disallowed piece allows it again; disallowing a locked piece drops the lock.

These options belong to Dark Fang: every weapon keeps its own.
