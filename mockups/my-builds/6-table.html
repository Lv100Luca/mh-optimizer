Idea 6 · One table, every piece against every skill

  1. 1The build is the table. One row per piece, one column per skill, a level in each cell. Targets come first in gold. There is nothing else on the page, so nothing is below the fold.
  2. 2The piece cell holds the picker, its slots and the set bonus / group it brings. Empty kinds are rows too: "choose arms" sits where the piece will go, so you see the gap in the sums.
  3. 3Every jewel is its own sub-row under its piece, levels in blue. An empty slot is a sub-row with "+ jewel". Swapping a jewel changes exactly one line, and you see which.
  4. 4The footer adds up against Wanted. Green met, amber short, red over the cap. Critical Boost is the only one met so far, and the blue sub-rows show it comes from two jewels, not from a piece. The editor today shows these sums on a card at the very bottom.
  5. 5Set and Group are piece counts per row; the footer lists each set with its count against the 2 / 4 and 3 piece steps.
  6. 6Click a column header for where to get that skill (idea 1's list). The first column and the header stay put; the rest scrolls sideways inside the card when there are many skills.
  7. 7Not solved: nothing here helps you choose a piece, the table only shows what you picked. With 15+ skills it gets wide and the headers hard to read. Set bonuses are counts, not skills, so their effects are not in the sums. Damage is illustrative.
